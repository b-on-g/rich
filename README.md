# $bog_rich

Редактор форматированного текста для $mol и вид для показа того же содержимого. Без Базы, сети и хранилищ: хозяин сам решает, куда положить данные.

[Демо](https://b-on-g.github.io/rich/)

```tree
<= Edit $bog_rich_edit
	hint \Сообщение…
	length_max 4096
	content? <=> content? null
	submit_with_enter true
	submit? <=> send? null
<= View $bog_rich_render
	content <= content?
```

## Содержимое

`$bog_rich_content`: `{ text, entities }`. Позиции в UTF-16, диапазоны полуоткрытые. HTML нигде не хранится.

| `type` | Что это | Поля |
| --- | --- | --- |
| `bold`, `italic`, `underline`, `strikethrough` | начертания | |
| `spoiler` | скрытый текст | |
| `code` | моноширинный фрагмент строки | |
| `blockquote` | цитата, целые абзацы | `collapsed` |
| `pre` | блок кода, целые абзацы | `language` |
| `text_link` | ссылка | `url` |
| `date_time` | момент времени, неделимый | `timestamp`, `format`, `timezone` |

`$bog_rich_normalize` приводит чужие данные к правильному виду: негодное отбрасывает, текст сохраняет. Стиль на выделении с несовместимыми кусками ложится на допустимые части.

- `$bog_rich_trim`, `$bog_rich_slice`, `$bog_rich_replace`, `$bog_rich_insert` сдвигают стили вместе с текстом.
- `$bog_rich_preview` — текст для превью и уведомлений, скрытое заменено.
- `$bog_rich_html` и `$bog_rich_html_parse` — обмен через буфер. Чужие узлы в документ не попадают.

## $bog_rich_edit

- `content?` — содержимое. Замена снаружи стирает историю и выделение.
- `enabled`, `hint`, `length_max`, `submit_with_enter`, `submit?`.
- `paste_files?` — файлы из буфера, редактор их не трогает.
- `selection?` — `{ anchor, focus }`, `bring()` — фокус с кареткой на прежнем месте.
- `format_apply`, `format_state`, `undo`, `redo`.

Меню одно для мыши и пальца: кнопка в поле или правый клик по выделению. Без выделения остаётся системное меню с орфографией.

Набор внутри строки делает браузер, чтобы работали IME, автозамена и голосовой ввод; модель догоняет его по `input`. Переносы, вставку, удаление через блоки и стили делает модель.

## Ограничения

- Подсветка кода общая, `language` только подпись.
- Ctrl/Cmd+Shift+N, Ctrl/Cmd+Shift+P и подобные браузер может забрать себе. Команда остаётся в меню.
- Кнопку в системное меню телефона веб добавить не даёт.
- Проверено в Chrome. Firefox, Safari, iOS и Android ещё нет.

## Подключение и тесты

Репозиторий в MAM: `bog/rich/`. Прогон: `npm exec mam@latest bog/rich/demo`.
